# Candy Store Income Calculator 🍬

## 📌 About the Project

This is a beginner-friendly Python program that calculates the net income of a candy store. The user enters the earnings from six products, followed by staff expenses and other expenses. The program calculates the total income and net income.

## 🚀 Features

- Input earnings for six products.
- Calculate total income.
- Enter staff expenses.
- Enter other expenses.
- Calculate the final net income.
- Display formatted financial results.

## 🛠️ Technologies Used

- Python 3
- Variables and data types
- `input()` and `print()`
- Integer conversion using `int()`
- Arithmetic operations
- Formatted strings (f-strings)

## 🧮 How It Works

**Step 1:** The user enters the earnings from six products.

**Step 2:** The program adds all product earnings to calculate the total income.

```python
income = bubblegum + toffee + iceCream + milkChocolate + doughnut + pancake
```

**Step 3:** The user enters staff expenses and other expenses.

**Step 4:** The program subtracts both expenses from the total income.

```python
netIncome = income - staffExpenses - otherExpenses
```
